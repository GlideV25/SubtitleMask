字幕遮挡条 (SubtitleMask)
==========================

用途：播放双语字幕视频时，用一条置顶黑条盖住中文那一行字幕。

基本操作
--------
双击 SubtitleMask.exe 即可出现黑条（默认在主屏底部中央，宽约为屏幕的 2/3）。
启动时不会抢当前播放器的焦点。

  移动    ：按住黑条内部拖动（中心 X 附近除外）
  调整长宽：拖动黑条的上下左右边缘或四个角
  关闭    ：鼠标移到黑条上，中心会浮现 X，点击 X 关闭
  透明度  ：鼠标悬停在黑条上，按住 Ctrl 滚动滚轮，以 5% 步进调整（25%–100%）
  右键菜单：不透明度（100%/90%/…/30%）
            高度预设（40/56/72/90 px）
            始终显示关闭按钮 X（勾选后 X 常驻，便于随时关闭）
            重置位置和大小 / 退出

保存
----
位置、大小、不透明度会自动保存：
  优先保存到 exe 同目录的 SubtitleMask.ini
  如果该目录不可写（例如放在 Program Files），则保存到
  %APPDATA%\SubtitleMask\settings.ini
删除 SubtitleMask.ini 后重新启动即可恢复默认位置和大小。

注意
----
播放器请使用“窗口化”或“无边框全屏”模式。部分播放器的“独占全屏”
会绕过 Windows 桌面合成，任何置顶窗口（包括本工具）都会被盖住。

系统要求
--------
Windows 10 / 11，无需安装；依赖系统自带的 .NET Framework 4.x。

源码
----
src\SubtitleMask.cs   程序源码（C# / WinForms）
src\build.cmd         重新编译：双击运行即可，输出到上一级目录
src\app.manifest      高 DPI 声明
src\icon.ico          图标
